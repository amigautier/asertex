    INSTRUCTIVO DE USO KIT CONTROL DE DERRAMES OLEOFÍLICOS

    ELEMENTOS QUE COMPONEN EL KIT:

    ELEMENTOS DE PROTECCION PERSONAL: chaleco, guantes, tapabocas gases, linterna. De acuerdo a la capacidad del kit, encontrará estos elementos.

    BARRERAS OLEOFILICAS: se usan para contener rodeado el derrame.

    PAÑOS ABSORBENTES OLEOFILICOS: se usan para absorber el derrame, permiten recuperar parte del líquido derramado (en caso que esta se pueda reutilizar), Éstas son hidrofóbicas; es decir, repelen el agua al igual que las barreras.

    ABSORBENTE GRANULADO: musgo que permite absorber derrames en terrenos escabrosos en zonas verdes o agua. Este material no permite recuperación de líquido porque encapsula v se biodegrada con él.

    CINTA DE SEÑALIZACIÓN: es utilizada para delimitar el área donde ha ocurrido el incidente o derrame.

    TACOS DE MADERA (CALAJANES): Se usan para cubrir el orificio donde se produce la fuga.

    MASILLA EPÓXICA: ésta se usa mezclando las 2 barras que viene en la caja similares a la plastilina y se cubre el orificio para evitar la fuga del líquido. Se puede utilizar con los tacos de madera.

    MARTILLO DE CAUCHO: éste se usa para insertar los tacos de madera (calajanes) en orificios donde se produce la fuga. Estos martillos deben ser fabricados en materiales que no produzcan chispa.

    DESENGRASANTE BIODEGRADABLE: es usado para limpiar el área contaminada después de recoger el derrame y evitar mayor contaminación.

    PALA PLÁSTICA ANTICHISPA: sirve para recoger el material absorbente granulado.

    BOLSAS ROJAS: son usadas para meter en ellas los materiales contaminados al terminar el proceso de limpieza.

    ¿QUÉ HACER EN CASO DE UN DERRAME?
    1. Revise en la ficha técnica que tipo de líquido es el derramado.
    2. Utilice los elementos de protección encontrados en el kit de derrames Su seguridad es lo primero.
    3. Según la dimensión del derrame proceder según las indicaciones de la persona encargada.
    4. El kit tiene una capacidad de acción, tenga en cuenta cual es.
    5. Rodee con las barreras oleofilicas el derrame para contenerlo.
    6. Detenga la fuga con los elementos indicados para este fin.
    7. Delimite el área con la cinta peligro para evitar el paso de personal o indicar peligro.
    8.Utilice los paños absorbentes o el granulado según el área donde ocurrió el derrame.
    9. Para recogerlo utilice el desengrasante para limpiar de una manera veloz el área contaminada después recoger la mayor cantidad del líquido derramado.
    10. Todo el material contaminado debe ser recogido en bolas dispuestas para tal fin.
    11. Entregue estas bolsas para disposición final según instrucciones.
